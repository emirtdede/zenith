## 3. What the software does

Zenith diagnoses and repairs Windows computers. Some actions change the system:
they stop services, delete temporary files, reset network stacks, rebuild caches,
or restart the computer. Each action declares a reversibility tier, and an action
that cannot be rolled back says so before it runs.

You are responsible for reviewing the action you approve. The application
creates a snapshot where the tier allows it, but a snapshot is not a backup of
your documents.
