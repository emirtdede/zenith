# 10-02 - Deficiency Register

| Field | Value |
| :--- | :--- |
| Document ID | ZEN-AUD-002 |
| Version | 2.0.0 |
| Owner | Everyone (each row has a named closure artifact) |
| Scope | Every defect in v1.0.0 (DEF-001…DEF-042) and every gap opened and worked in 2.0.0 (DEF-043…DEF-168) |
| Rule | An id closes when the artifact exists and the named command passes - never by editing this table |
| Closes | No single defect - this is the register itself: the ledger of all 146 rows |

Two kinds of entry live here and are marked differently:

- **v1.0.0 defect** - the published master specification contained the flaw. Status is `Closed` when
  the 2.0.0 library *and the shipped code* fix it.
- **2.0.0 gap** - an honest limitation of what was built. Status stays `Open` until the artifact exists.

The distinction matters: a register that marks everything closed is not a register. Nine rows
below are deliberately `Open` (three of them blocker-class: DEF-028, DEF-047, DEF-050).
