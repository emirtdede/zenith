## Product name

Zenith

## Short description

Diagnose and repair your Windows PC, safely.

## Description

Zenith measures what is actually wrong with a Windows computer, explains the
result in plain language, and repairs only what you approve.

Every action declares how far it can be undone. Before a repair runs, Zenith
takes a snapshot where the action allows one, so a change you regret has a path
back. A permanent action says so before the click.

Zenith works offline. There is no account, no advertising, and no telemetry
unless you turn it on.

What it covers:

- 22 named repair actions across cleanup, network, Windows component, and device
  families, each with a reversibility tier and a written scope.
- A measured health score with units, a timestamp, and a source for every value.
- Snapshot history with restore and verification.
- An audit trail of what ran, when, and with which result.
- A readable PowerShell export of every action, usable on a machine that has
  never had Zenith installed.
- 14 colour palettes in light and dark modes, a custom accent colour, and a
  high-contrast mode.
- 73 selectable languages, with full English and Turkish catalogues and an
  English fallback disclosed in the picker.
- An app lock with a 4, 6, or 8 digit PIN or a password.
- A settings export and import, and a 30-day trash for deleted items.

## Feature bullets for the listing

- Diagnose first, change second: measurements before mutations.
- Four reversibility tiers and a snapshot you can restore.
- 22 documented actions, no hidden scripts.
- Local-first: no account, no telemetry by default, works offline.
- 14 palettes, light and dark, custom accent.
- 73 languages with right-to-left support.
- Keyboard first: command palette, context menu from the keyboard, visible focus.
- Export any action as a PowerShell script.
